# App Store screenshots

Run `npm run marketing:app-store` to render the current iPhone and iPad campaigns.

## Directories

- `raw/iphone-17-pro/` contains native 1206 × 2622 captures from the dedicated screenshot
  simulator. Do not edit these files.
- `raw/ipad-pro-13/` contains native 2752 × 2064 landscape captures from the dedicated iPad
  simulator. Do not edit these files.
- `iphone-6.9/` contains opaque 1320 × 2868 release candidates for the 6.9-inch App Store slot.
- `ipad-13-landscape/` contains opaque 2752 × 2064 release candidates for the 13-inch iPad
  App Store slot.

The generated assets use real Suwatte UI and the rights-tracked fixtures below.

Apple accepts one to ten screenshots. The first one to three can appear in search results. The
current campaign contains eight screenshots for each device family and starts with the core
library and reading experience. History and Insights complete the product story. See Apple's current
[screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)
and [asset best practices](https://developer.apple.com/app-store/asset-best-practices/) before
submission.

The iPad campaign is rendered from native landscape iPad captures. Do not enlarge the iPhone UI
into an iPad frame or substitute these compositions for other device families without checking
Apple's current accepted sizes.
