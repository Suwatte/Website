title: Widgets and Daily Goals
description: Resume a title, see chapter updates, and check your reading goal from a widget.
---

Suwatte has **Continue Reading**, **Latest Updates**, and **Daily Goal** widgets.
Open the app and read a title to give the widgets something to show.

## Choose a Widget

| Widget | Where to Add It | What a Tap Opens |
| --- | --- | --- |
| Continue Reading | Home Screen or Lock Screen | The selected title's reading destination. |
| Latest Updates | Home Screen | A title page, or the Updates feed when you tap the header. |
| Daily Goal | Lock Screen | Insights, or goal setup if no goal is set. |

Continue Reading has small, medium, large, and extra-large Home Screen layouts.
Its Lock Screen layouts are circular, rectangular, and inline.
Latest Updates has small, medium, large, and extra-large layouts.
Daily Goal uses a circular Lock Screen layout.
Your device determines which layouts you can add.

## Add a Widget

For the Home Screen, open your device's widget gallery and search for **Suwatte**.
Choose a widget and a size, then add it.

For the Lock Screen, open its customization screen and select the widget area.
Choose **Suwatte**, then add Continue Reading or Daily Goal.

## Set a Daily Goal

1. Open **Settings → Startup & Activity**.
2. Choose a time under **Daily Reading Goal**.
3. Read in Suwatte to add saved reading time toward the goal.

The goal also appears in For You and Insights.
Select **Off** to stop using a goal.
Reading in Incognito Mode does not add saved reading time.

## If a Widget Looks Out of Date

Open Suwatte to let it save fresh widget data.
Your device controls when a widget redraws, so a change can take time to appear.
Latest Updates shows chapters found by update checks, rather than predicted release dates.

The reader's Resume Live Activity is a separate feature.
It returns you to an open reading session and does not replace a widget.
