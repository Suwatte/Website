---
title: A Device-Only Library
description: Choose a library kept on this device and decide how to switch back to iCloud.
---

Suwatte can use an iCloud library or a separate device-only library.
The device-only library keeps its library records on this device without syncing them to your other devices.
The iCloud library is kept when you switch away from it.

## Switch to This Device

1. Open **Settings** and find the **iCloud** section.
2. Turn off **Sync Library with iCloud**.
3. Choose how to start the device-only library.
4. Wait for preparation to finish.
5. Close Suwatte from the app switcher and open it again.

Choose **Copy iCloud Library to This Device** to start with a copy of your iCloud library.
Choose `Use This Device's Previous Library` if that option appears and you want to return to that library.
Choose **Start Empty** to start without library records.
If a device-only library already exists, Start Empty replaces it.

The change takes effect after you close and reopen the app.

## Return to iCloud

Turn on **Sync Library with iCloud** in Settings and choose one of these actions.

- **Use iCloud Library** opens the kept iCloud library without merging the device-only library.
- **Merge This Device's Library into iCloud** adds the device-only library's records to iCloud before switching.

Close Suwatte from the app switcher and open it again to finish the switch.
Choose the merge action only when you want records from this device added to the iCloud library.

## What This Choice Controls

This switch controls the library records used by Suwatte.
It does not move your book files out of iCloud Drive or change your server's storage.
Source and server requests still use the network when you browse or download from them.

Use [Backups](/docs/backups/) to keep a separate copy of supported library data before replacing a library.
