---
title: Book Fonts
description: Add your own fonts for EPUBs and source text chapters.
---

You can add fonts for books with text that adjusts to the screen.
This includes most EPUB novels and supported source text chapters.
Fonts do not change text drawn into comic images, fixed-layout book pages, or PDF pages.

## Add a Font

1. Open **Settings → Book Reader**.
2. Select **Reflowable** under **Book Layout**.
3. Open **Font** and select **Add Font** under **Your Fonts**.
4. Choose a `.ttf`, `.otf`, or `.woff` file in Files.
5. Select the font in the list when you want to use it.

You can also add fonts from an open book's reader settings.
After a successful import, the imported family is selected.
The open book can use the font without being closed and reopened.

Suwatte copies imported font files into its own storage.
Add the fonts on each device where you want to read with them.

## If a Font Cannot Be Added

Font collections such as `.ttc` and `.otc` are not supported.
Use individual font files instead.
A family that is already available as a built-in choice cannot be added as another choice.

The font list previews each family.
Choose another font if its character support does not suit the book's language.

## Delete a Font

Swipe a font under **Your Fonts** and select **Delete**.
If that font is selected, the picker returns to **Publisher**.
Keep the original font file if you want to add it again later.
