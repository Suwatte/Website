---
title: Search Filters
description: Choose which local libraries, servers, and sources the Search tab searches.
---

The **Search** tab can search your local library, connected servers, and installed sources.
Use its filter control to choose where to search.

## Choose Search Locations

1. Open **Search** and select the filter control.
2. Under **Search In**, turn **Local Library**, **Servers**, or **Sources** on or off.
3. Choose the individual libraries, servers, or sources you want to include.
4. Select **Done** to return to the results.

Changes are saved as you make them.
Select **Reset** to return to the default search choices.

Turn on **Hide Sections Without Results** to keep empty sections out of the results.
Turn it off if you want to see which included locations had no matches.

## Use a Source's Own Filters

Shared filters choose search locations.
They do not replace a source's or server's own search filters.
Select **View More** on a results section to open that location's search and use its filters.

## Find More Titles in a Genre

Tap a supported genre on a title page to browse that genre.
The destination depends on where the title comes from.
A source or server title opens its matching search when one is available.
A source-library title can open that genre in your library.
