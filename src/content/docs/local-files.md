Suwatte reads four file formats from your device.

| Format | What it is |
| --- | --- |
| **CBZ** | A comic archive. It is a ZIP file of images. |
| **CBR** | A comic archive. It is a RAR file of images. |
| **PDF** | A document with a fixed layout. |
| **EPUB** | A book with a flexible layout. |

A CBZ file and a CBR file hold page images. A PDF file and an EPUB file open in the publication
reader. See [Novels and PDFs](/docs/publications/).

## Add your files

Select a folder with the Files app. Suwatte reads the folder, finds the files that it supports,
and adds them to your library.

The files stay where they are. Suwatte makes an index. It does not copy the files into itself.

Because it is a scan, you can add more files to the same folder later. Suwatte finds them on the
next scan.

## How they behave

A local file is a normal library entry. Put it in a collection, set a flag on it, bookmark it, and
filter it. Suwatte records your progress in the same way.

## Thumbnails

Suwatte keeps the cover of each local file on the device.

To see the size of that cache, go to
**Settings → Advanced → Network & Caches → Thumbnail Cache**. The app reports the source
thumbnails and the local thumbnails separately.

To empty the cache, use **Clear Thumbnail Cache**. This does not delete your files. Suwatte makes
the thumbnails again when it needs them.
