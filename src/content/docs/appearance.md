Choose a theme in **Settings → Library & Appearance → Theme**.
App themes change Suwatte's screens, menus, and controls.
Book backgrounds and image-reader filters have their own settings.

## Choose a Theme

Select **System**, **Light**, or **Dark** under **Standard**.
System follows your device's appearance.
Use **Accent Color** to change the color of buttons and selected controls in these themes.

Preset themes have their own accent colors.
A preset with two color swatches has separate light and dark palettes.
It follows your device's appearance.
A preset with one palette keeps its colors in both appearances.

## Create a Theme

1. Open **Theme** and select **New Theme**.
2. Enter a name.
3. Set the colors and check the preview.
4. Select **Save** to save and apply the theme.

Turn on **Adapt to Light and Dark** to create separate palettes.
Select **Light** or **Dark** under **Appearance** to edit each palette.
With this option off, the theme uses one palette in both appearances.

## Import or Share a Theme

Select **Import Theme** and choose a `.stt_theme` file in Files.
Suwatte adds the theme and applies it.
You can also open a shared theme file with Suwatte.

Touch and hold a custom theme to open **Edit Theme**, **Export Theme**, or **Delete Theme**.
Export saves a `.stt_theme` file that you can send to someone else.

To make a theme in a web browser, use the [theme builder](/theme-builder/).
It shows your colors on an iPhone or iPad and downloads a `.stt_theme` file.

## Change the App Icon

Open **App Icon** at the top of the Themes screen and choose an icon.
This control appears when your device supports alternate app icons.
