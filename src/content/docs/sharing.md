---
title: Sharing Source Links
description: Send a link to a source, title, chapter, list, or search in Suwatte.
---

Use **Share** on a source screen to send a Suwatte link.
Supported destinations include a source's home, a title, a chapter, a list, a search, and a source page.
The link opens that destination in the recipient's app.

## Send a Link

1. Open the destination that you want to share.
2. Open its menu and select **Share**.
3. Choose where to send the link from the share sheet.

The link points to the source destination.
It does not send the book file or your reading progress.
Share actions are not available for server-hosted sources, which depend on your own server connection.

## Open a Shared Link

Open the link on a device with Suwatte installed.
The website forwards the link to the app.
If the app does not open, select **Open in Suwatte** on the page.
The page also has a download link for people who need the app.

If the source is installed, Suwatte opens the destination.
If it is missing and the link includes a source list, Suwatte asks whether to install it.
Check the source and list before selecting **Install**.
After installation, the app continues to the shared destination.

## If the Link Does Not Open

- Install the source first if the link has no source list.
- Update Suwatte if the app says the link or source needs a newer version.
- Ask the sender for a new link if the page says the link is incomplete.
- Check Safe Mode if the needed source is hidden.

Open the link on an iPhone or iPad.
The website does not provide a web reader for shared chapters.
