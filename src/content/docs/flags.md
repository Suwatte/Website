A flag records your position with a title. Each title has one flag.

## The flags

| Flag | What it means |
| --- | --- |
| **Reading** | You read it now. |
| **Planned** | You want to start it. |
| **Completed** | You finished it. |
| **Dropped** | You stopped, and you will not go back. |
| **Rereading** | You read it again. |
| **Paused** | You stopped for now, and you can go back. |

A title with no flag shows as **None**.

## Set a flag

Set a flag on the detail page of a title. To set the same flag on many titles, select them in the
library first.

## Flags as collections

Turn **Settings → Reading → Library & Appearance → Flag Collections** on. You then get one library
shelf for each flag.

This is the quickest way to see what you started but did not finish.

With Compact Library on, you can open the Library tab directly to one of these shelves. Open it to
**Reading**, for example.

## Flags and update checks

An update check can use your flags. Open
**Settings → Sources → Source Updates → Selected Filters**. Select the publication statuses and
the flags to check. One of each must stay selected.

This is how you stop the checks on the titles that you dropped.

The same page has **Skip Conditions**:

- **Has Unread Chapters** skips a title that you did not read to the end. If you are 20 chapters
  behind, you do not need to know about chapter 21.
- **Not Started Yet** skips a title that you never opened.
