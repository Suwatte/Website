A new install has nothing to browse. A source gives Suwatte something to read.

## What a Source plugin is

A Source is a small plugin. It knows how to read one website: how to search it, how to list the
chapters of a series, and how to get the pages of a chapter. Suwatte runs it on your device.

Suwatte comes with no sources. It does not operate a directory of sources. You supply a **source
list**, which is an address that points at a set of sources.

## Install from a source list

1. Go to **Settings → Sources → Manage Sources**.
2. Add a source list by its address.
3. Suwatte gets the list. It shows the name, the version, the languages and the content rating of
   each source.
4. Install the sources that you want.

A source can need a newer app than you have. The app shows it but does not let you install it.
Update Suwatte first.

## Find something to read

After you install one source:

- **Home** shows the home page of each source that has one.
- **Search** asks all of your sources at the same time and groups the results by source.
- Open a result to see the title, its chapters, and the **Save to Library** action.

## Keep your sources current

A source breaks when the site that it reads changes. Sources get updates often.

Open **Settings → Sources → Source Updates**:

- **Update Sources Automatically** checks your sources one time each day.
- **Check for Updates in Background** looks for new chapters while you do not use the app.

Keep the first option on.

## If a source stops working

1. Look for a source update. The author of the source repairs most faults.
2. Read **Settings → Advanced → Logs** to see the error.
3. If the site uses Cloudflare, Suwatte opens a web view so that you can answer the challenge.

Read [Correct a fault](/docs/troubleshooting/) for more.
