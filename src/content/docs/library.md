title: The library and collections
description: How the library is arranged, how to make collections, and how to open the Library tab where you want.
---

The library holds what you saved. A title from a source, a server or a file all go to the same
place.

## The shelves that always exist

- **All Titles** holds all that you saved.
- **Downloaded Titles** holds each title with chapters on this device.
- **Saved For Later** holds the titles that you did not commit to.
- **Servers** holds the titles on a connected server.

## Collections

You make a collection, and a title can be in more than one. Make one from the library, then add
titles one at a time or in a group.

The app also uses collections in other places. In
**Settings → Sources → Source Updates → In Collections**, you can limit the update checks to some
collections. This helps when you follow 50 series but want new chapters for only 5 of them.

## Flag collections

Suwatte can make a collection from each flag. Turn
**Settings → Reading → Library & Appearance → Flag Collections** on. You then get one shelf for
each flag: Reading, Planned, Completed, Dropped, Rereading and Paused.

See [Flags](/docs/flags/).

## Compact Library

The Library tab shows the list of collections, and you touch one to open it.

**Compact Library** removes that step. The Library tab opens one collection directly. Turn it on
in **Settings → Reading → Library & Appearance**, then set **Open Library To**:

- **Last Opened** opens the collection that you used last.
- A fixed value opens the same collection each time. Select All Titles, Downloaded Titles, Saved
  For Later, Servers, one of your collections, or one flag collection.

## Filters

You can filter All Titles by content type, by flag and by other attributes. The filters reset when
you close the app.

To keep them, turn **Persist All Titles Filter** on in
**Settings → Reading → Library & Appearance**.

## Appearance

Open **Settings → Reading → Library & Appearance**:

- **Tile Style**. `Compact` puts the title on the cover. `Separated` puts it below the cover.
- **Items Per Row**. Set a value from 2 to 12, for portrait and for landscape.
